# Szablon raportu UX

[Mapa wiedzy](../README.md)

Skill [ux-audit](../../.claude/skills/ux-audit/SKILL.md) składa ten układ automatycznie w `raport.html`.

1. **Podsumowanie**: 2–3 zdania, liczby, wynik checklisty.
2. **Zakres i metoda**: adres, data, urządzenia, ograniczenia.
3. **Persona** i scenariusz.
4. **Ścieżka**: mapa nastroju, a dla każdego etapu zrzut, myśl, obserwacja i problemy.
5. **Problemy**, od najwyższej wagi:

   | Pole | Wartość |
   |---|---|
   | ID i tytuł | F-01 … |
   | Waga 1–4 | częstość, wpływ, trwałość |
   | Krok i dowód | zrzut, kod, pomiar |
   | Punkty checklisty i źródła | np. KOL-01, WCAG 1.4.3 |
   | Poprawka i nakład | co zmienić, S/M/L |

6. **Plan napraw**: waga, potem nakład.
7. **Pełna checklista**: wynik każdego punktu.
8. **Co działa dobrze**.
