
# Kategorie stron internetowych

## 1. Wyszukiwarki internetowe

Przykłady:
- Google
- Bing

Główne funkcje:
- Wyszukiwanie informacji.
- Wyświetlanie wyników.
- Podpowiedzi wyszukiwania.
- Filtrowanie wyników.

Co należy testować:
- Działanie wyszukiwarki.
- Poprawność wyników.
- Obsługę pustych zapytań.
- Nawigację między wynikami.

## 2. Media społecznościowe

Przykłady:
- Facebook
- Instagram
- TikTok
- Pinterest

Główne funkcje:
- Rejestracja i logowanie.
- Publikowanie treści.
- Komentarze.
- Wiadomości.
- Obserwowanie użytkowników.

Co należy testować:
- Dodawanie postów.
- Dodawanie komentarzy.
- Wysyłanie wiadomości.
- Zarządzanie profilem.
- Działanie powiadomień.

## 3. Sklepy internetowe i marketplace

Przykłady:
- Amazon
- eBay
- Apple Store

Główne funkcje:
- Wyszukiwanie produktów.
- Filtrowanie.
- Koszyk.
- Zamówienia.
- Opinie użytkowników.

Co należy testować:
- Wyszukiwanie produktów.
- Dodawanie produktów do koszyka.
- Aktualizację ilości produktów.
- Obliczanie ceny.
- Proces składania zamówienia.

## 4. Platformy streamingowe

Przykłady:
- YouTube
- Netflix
- Spotify

Główne funkcje:
- Odtwarzanie treści.
- Wyszukiwanie.
- Playlisty.
- Profile użytkowników.
- Rekomendacje.

Co należy testować:
- Odtwarzanie treści.
- Zatrzymywanie i wznawianie odtwarzania.
- Wyszukiwanie.
- Zapisywanie ulubionych treści.
- Działanie kont użytkowników.

## 5. Platformy rezerwacyjne

Przykłady:
- Booking.com
- Airbnb

Główne funkcje:
- Wyszukiwanie ofert.
- Filtrowanie wyników.
- Wybór dat.
- Rezerwacje.
- Opinie użytkowników.

Co należy testować:
- Wyszukiwanie dostępnych ofert.
- Działanie filtrów.
- Wybór dat.
- Proces rezerwacji.
- Poprawność informacji o ofercie.

## 6. Platformy edukacyjne i informacyjne

Przykłady:
- Wikipedia
- Stack Overflow
- Mozilla

Główne funkcje:
- Wyszukiwanie informacji.
- Przeglądanie artykułów.
- Kategorie tematyczne.
- Dodawanie treści.
- Nawigacja.

Co należy testować:
- Wyszukiwanie artykułów.
- Otwieranie podstron.
- Działanie linków.
- Czytelność treści.
- Strukturę informacji.

## 7. Platformy programistyczne

Przykłady:
- GitHub

Główne funkcje:
- Tworzenie repozytoriów.
- Zarządzanie plikami.
- Zgłaszanie problemów.
- Współpraca nad projektami.

Co należy testować:
- Tworzenie repozytoriów.
- Dodawanie plików.
- Nawigację.
- Zarządzanie projektami.
- Uprawnienia użytkowników.

## 8. Podsumowanie

Każda kategoria stron internetowych posiada inne funkcje i wymagania.

Dlatego tester powinien dopasować checklistę do rodzaju strony oraz jej przeznaczenia.
