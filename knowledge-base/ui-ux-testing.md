
# UI i UX Testing

## 1. Czym jest UI Testing?

UI (User Interface) oznacza interfejs użytkownika.

UI Testing polega na sprawdzaniu wizualnych elementów strony internetowej i ich poprawnego wyświetlania.

### Co należy sprawdzać?

- Kolory i kontrast.
- Rodzaj i wielkość czcionek.
- Rozmieszczenie elementów.
- Wygląd przycisków.
- Obrazy i ikony.
- Spójność wyglądu wszystkich podstron.
- Czytelność tekstu.

### Przykład

Jeżeli przycisk na stronie jest niewidoczny lub tekst nachodzi na obraz, może to oznaczać problem z interfejsem.

## 2. Czym jest UX Testing?

UX (User Experience) oznacza doświadczenie użytkownika.

UX Testing polega na sprawdzaniu, czy użytkownik może łatwo i wygodnie korzystać ze strony.

### Co należy sprawdzać?

- Czy nawigacja jest intuicyjna?
- Czy użytkownik łatwo znajduje informacje?
- Czy formularze są proste w obsłudze?
- Czy komunikaty są zrozumiałe?
- Czy wykonanie zadania wymaga odpowiedniej liczby kroków?
- Czy strona jest wygodna w obsłudze?

### Przykład

Jeżeli użytkownik musi przejść przez wiele niepotrzebnych kroków, aby znaleźć produkt, może to oznaczać problem z UX.

## 3. Różnica między UI i UX

UI koncentruje się na wyglądzie interfejsu, natomiast UX koncentruje się na całym doświadczeniu użytkownika.

Przykład:

- UI: Czy przycisk jest dobrze widoczny?
- UX: Czy użytkownik rozumie, do czego służy przycisk?

## 4. Narzędzia

Przydatne narzędzia do analizy UI i UX:

- Google Chrome DevTools.
- Google Lighthouse.
- Google Material Design.
- Figma.

## 5. Podsumowanie

UI i UX są ważnymi elementami jakości strony internetowej. Dobry interfejs powinien być czytelny, spójny i łatwy w obsłudze.
