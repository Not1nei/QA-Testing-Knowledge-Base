
# Performance Testing

## 1. Czym jest Performance Testing?

Performance Testing to proces sprawdzania wydajności strony internetowej.

Pozwala ocenić szybkość działania, stabilność oraz zachowanie strony podczas korzystania przez użytkowników.

## 2. Główne cele

- Sprawdzenie czasu ładowania strony.
- Wykrywanie problemów z wydajnością.
- Ocena szybkości działania funkcji.
- Sprawdzenie stabilności strony.
- Poprawa komfortu użytkowania.

## 3. Co należy sprawdzać?

### Czas ładowania
- Jak szybko otwiera się strona główna?
- Jak długo ładują się podstrony?
- Czy obrazy ładują się prawidłowo?

### Wydajność
- Czy strona działa płynnie?
- Czy występują opóźnienia?
- Czy elementy reagują szybko na działania użytkownika?

### Stabilność
- Czy strona działa poprawnie podczas dłuższego korzystania?
- Czy występują błędy podczas ładowania?
- Czy strona zachowuje stabilność przy większej liczbie użytkowników?

## 4. Podstawowe rodzaje testów wydajnościowych

- Load Testing – sprawdzanie działania przy określonym obciążeniu.
- Stress Testing – sprawdzanie zachowania przy dużym obciążeniu.
- Spike Testing – sprawdzanie reakcji na nagły wzrost obciążenia.
- Endurance Testing – sprawdzanie działania przez dłuższy czas.

## 5. Narzędzia

- Google Lighthouse.
- Chrome DevTools.
- Apache JMeter.
- k6.

## 6. Podsumowanie

Performance Testing pomaga ocenić szybkość i stabilność strony internetowej oraz wykrywać problemy, które mogą utrudniać korzystanie z serwisu.
