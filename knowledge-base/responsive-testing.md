
# Responsive Testing

## 1. Czym jest Responsive Testing?

Responsive Testing to proces sprawdzania, czy strona internetowa poprawnie wyświetla się na urządzeniach o różnych rozmiarach ekranów.

Strona powinna być wygodna w obsłudze zarówno na komputerze, jak i na tablecie oraz telefonie.

## 2. Dlaczego jest ważne?

Użytkownicy korzystają ze stron internetowych na różnych urządzeniach.

Nieprawidłowa responsywność może powodować:
- Ucinanie tekstu.
- Nakładanie się elementów.
- Nieprawidłowe wyświetlanie obrazów.
- Problemy z nawigacją.
- Trudności z klikaniem przycisków.

## 3. Co należy testować?

### Komputer (Desktop)
- Poprawne rozmieszczenie elementów.
- Czytelność tekstu.
- Działanie menu.
- Prawidłowe wyświetlanie obrazów.

### Tablet
- Dopasowanie szerokości strony.
- Rozmieszczenie kolumn.
- Działanie menu.
- Czytelność treści.

### Telefon (Mobile)
- Działanie menu mobilnego.
- Wielkość przycisków.
- Czytelność tekstu.
- Brak poziomego przewijania, gdy nie jest potrzebne.
- Poprawne wyświetlanie formularzy.

## 4. Narzędzia

- Google Chrome DevTools.
- Responsive Design Mode.
- Google Lighthouse.

## 5. Przykładowy scenariusz testowy

1. Otwórz stronę internetową.
2. Uruchom narzędzia Chrome DevTools.
3. Włącz tryb urządzenia mobilnego.
4. Wybierz różne rozmiary ekranów.
5. Sprawdź rozmieszczenie elementów.
6. Przetestuj menu i przyciski.
7. Zapisz zauważone problemy.

## 6. Podsumowanie

Responsive Testing pozwala sprawdzić, czy strona internetowa jest dostosowana do różnych urządzeń i zapewnia wygodę użytkowania niezależnie od wielkości ekranu.
