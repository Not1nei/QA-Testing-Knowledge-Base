
# E-commerce Website Testing Checklist

## 1. Cel

Lista kontrolna przeznaczona do testowania sklepów internetowych i platform sprzedażowych.

Przykłady: Amazon, eBay, Apple Store.

## 2. Produkty
- [ ] Lista produktów wyświetla się poprawnie.
- [ ] Zdjęcia produktów są widoczne.
- [ ] Nazwy produktów są czytelne.
- [ ] Ceny produktów są prawidłowo prezentowane.
- [ ] Szczegóły produktu otwierają się poprawnie.

## 3. Wyszukiwanie i filtrowanie
- [ ] Wyszukiwarka produktów działa.
- [ ] Wyniki odpowiadają zapytaniu.
- [ ] Filtry działają poprawnie.
- [ ] Sortowanie produktów działa.
- [ ] Można usunąć zastosowane filtry.

## 4. Koszyk
- [ ] Można dodać produkt do koszyka.
- [ ] Można usunąć produkt z koszyka.
- [ ] Można zmienić ilość produktów.
- [ ] Cena aktualizuje się poprawnie.
- [ ] Koszyk zachowuje produkty podczas nawigacji.

## 5. Zamówienia
- [ ] Formularz zamówienia działa.
- [ ] Dane klienta są walidowane.
- [ ] Adres dostawy można wprowadzić.
- [ ] Podsumowanie zamówienia jest poprawne.
- [ ] Użytkownik otrzymuje potwierdzenie zamówienia.

## 6. Płatności
- [ ] Dostępne metody płatności są widoczne.
- [ ] Nieprawidłowe dane płatnicze są obsługiwane.
- [ ] Status płatności jest odpowiednio wyświetlany.
- [ ] Informacje o płatności są czytelne.

## 7. Konto użytkownika
- [ ] Rejestracja działa.
- [ ] Logowanie działa.
- [ ] Można się wylogować.
- [ ] Dane profilu można edytować.
- [ ] Historia zamówień jest dostępna dla uprawnionego użytkownika.

## 8. Podsumowanie

Testowanie sklepu internetowego powinno obejmować cały proces zakupowy: od wyszukiwania produktu do potwierdzenia zamówienia.
