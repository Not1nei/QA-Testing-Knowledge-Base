
# General Website Testing Checklist

## 1. Cel

Uniwersalna lista kontrolna do sprawdzania podstawowych funkcji i jakości dowolnej strony internetowej.

## 2. Strona główna
- [ ] Strona główna otwiera się poprawnie.
- [ ] Logo jest widoczne i działa.
- [ ] Wszystkie obrazy wyświetlają się poprawnie.
- [ ] Teksty są czytelne.
- [ ] Nie występują błędy wizualne.

## 3. Nawigacja
- [ ] Menu główne działa poprawnie.
- [ ] Wszystkie linki prowadzą do właściwych stron.
- [ ] Można wrócić do strony głównej.
- [ ] Nawigacja jest zrozumiała.
- [ ] Nie występują niedziałające linki.

## 4. Przyciski i formularze
- [ ] Wszystkie przyciski reagują na kliknięcie.
- [ ] Formularze przyjmują poprawne dane.
- [ ] Nieprawidłowe dane są odpowiednio obsługiwane.
- [ ] Komunikaty o błędach są czytelne.
- [ ] Formularze można wysłać.

## 5. Wyszukiwanie
- [ ] Pole wyszukiwania działa.
- [ ] Wyniki są wyświetlane poprawnie.
- [ ] Można wyszukiwać różne frazy.
- [ ] Brak wyników jest odpowiednio komunikowany.

## 6. Responsywność
- [ ] Strona działa na komputerze.
- [ ] Strona działa na tablecie.
- [ ] Strona działa na telefonie.
- [ ] Menu mobilne działa poprawnie.
- [ ] Elementy nie nachodzą na siebie.

## 7. Wydajność
- [ ] Strona ładuje się poprawnie.
- [ ] Obrazy nie powodują nadmiernych opóźnień.
- [ ] Podstawowe funkcje działają płynnie.

## 8. Dostępność
- [ ] Strona obsługuje nawigację klawiaturą.
- [ ] Tekst ma odpowiedni kontrast.
- [ ] Obrazy posiadają odpowiednie opisy alternatywne.
- [ ] Formularze mają czytelne etykiety.

## 9. Wyniki testowania

Status:
- PASS – test zakończony powodzeniem.
- FAIL – wykryto błąd.
- BLOCKED – test nie może zostać wykonany.
- NOT TESTED – test nie został wykonany.
