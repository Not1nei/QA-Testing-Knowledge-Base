
# Streaming Website Testing Checklist

## 1. Cel

Lista kontrolna do testowania platform streamingowych.

Przykłady: YouTube, Netflix, Spotify.

## 2. Wyszukiwanie
- [ ] Wyszukiwarka działa poprawnie.
- [ ] Wyniki odpowiadają zapytaniu.
- [ ] Można wyszukiwać różne treści.
- [ ] Można otworzyć wybraną treść.

## 3. Odtwarzanie
- [ ] Materiał można uruchomić.
- [ ] Można zatrzymać odtwarzanie.
- [ ] Można wznowić odtwarzanie.
- [ ] Regulacja głośności działa.
- [ ] Można zmienić pozycję odtwarzania.
- [ ] Obraz i dźwięk działają poprawnie, jeśli są dostępne.

## 4. Konto użytkownika
- [ ] Logowanie działa.
- [ ] Można się wylogować.
- [ ] Profil użytkownika wyświetla się poprawnie.
- [ ] Ustawienia konta są dostępne.

## 5. Ulubione i playlisty
- [ ] Można dodać treść do ulubionych.
- [ ] Można usunąć treść z ulubionych.
- [ ] Można utworzyć playlistę, jeśli platforma oferuje tę funkcję.
- [ ] Można edytować playlistę.

## 6. Interfejs
- [ ] Przyciski odtwarzania są widoczne.
- [ ] Elementy sterujące działają.
- [ ] Informacje o treści są czytelne.
- [ ] Interfejs dostosowuje się do różnych urządzeń.

## 7. Podsumowanie

Testowanie platform streamingowych powinno obejmować wyszukiwanie treści, odtwarzanie, zarządzanie kontem oraz interakcję użytkownika z materiałami.
