
# Booking Website Testing Checklist

## 1. Cel

Lista kontrolna do testowania platform rezerwacyjnych.

Przykłady: Booking.com, Airbnb.

## 2. Wyszukiwanie ofert
- [ ] Wyszukiwarka działa poprawnie.
- [ ] Można wybrać lokalizację.
- [ ] Można wybrać datę przyjazdu i wyjazdu.
- [ ] Można określić liczbę gości.
- [ ] Wyniki wyszukiwania są wyświetlane poprawnie.

## 3. Filtrowanie i sortowanie
- [ ] Filtry cenowe działają.
- [ ] Można filtrować oferty według kategorii.
- [ ] Sortowanie wyników działa.
- [ ] Można usunąć wybrane filtry.

## 4. Szczegóły oferty
- [ ] Zdjęcia są widoczne.
- [ ] Opis oferty jest czytelny.
- [ ] Cena jest wyświetlana poprawnie.
- [ ] Informacje o dostępności są widoczne.
- [ ] Warunki rezerwacji są dostępne.

## 5. Rezerwacja
- [ ] Można wybrać ofertę.
- [ ] Formularz rezerwacji działa.
- [ ] Dane użytkownika są walidowane.
- [ ] Podsumowanie rezerwacji jest poprawne.
- [ ] Użytkownik otrzymuje potwierdzenie rezerwacji.

## 6. Konto użytkownika
- [ ] Można utworzyć konto.
- [ ] Można się zalogować.
- [ ] Można zobaczyć swoje rezerwacje.
- [ ] Można zarządzać rezerwacją zgodnie z jej warunkami.

## 7. Podsumowanie

Testowanie platform rezerwacyjnych powinno obejmować wyszukiwanie ofert, wybór terminów, filtrowanie oraz cały proces rezerwacji.
