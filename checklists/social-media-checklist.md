
# Social Media Website Testing Checklist

## 1. Cel

Lista kontrolna do testowania serwisów społecznościowych.

Przykłady: Facebook, Instagram, TikTok, Pinterest.

## 2. Rejestracja i logowanie
- [ ] Można utworzyć konto.
- [ ] Formularz rejestracyjny działa.
- [ ] Można zalogować się na konto.
- [ ] Można się wylogować.
- [ ] Nieprawidłowe dane są odpowiednio obsługiwane.

## 3. Profil użytkownika
- [ ] Profil użytkownika wyświetla się poprawnie.
- [ ] Można edytować podstawowe informacje.
- [ ] Można zmienić zdjęcie profilowe.
- [ ] Ustawienia prywatności są dostępne.

## 4. Publikowanie treści
- [ ] Można utworzyć post.
- [ ] Można dodać zdjęcie lub film.
- [ ] Można edytować własną treść.
- [ ] Można usunąć własny post.
- [ ] Opublikowana treść jest widoczna zgodnie z ustawieniami prywatności.

## 5. Interakcje
- [ ] Można dodawać komentarze.
- [ ] Można reagować na posty.
- [ ] Można obserwować innych użytkowników.
- [ ] Można udostępniać treści.

## 6. Wiadomości i powiadomienia
- [ ] Można wysłać wiadomość.
- [ ] Można odebrać wiadomość.
- [ ] Powiadomienia są wyświetlane poprawnie.
- [ ] Można zarządzać powiadomieniami.

## 7. Bezpieczeństwo i prywatność
- [ ] Ustawienia prywatności są dostępne.
- [ ] Można zarządzać widocznością treści.
- [ ] Dane prywatne nie są widoczne dla nieuprawnionych użytkowników.
- [ ] Można zgłaszać nieodpowiednie treści.

## 8. Podsumowanie

Testowanie serwisów społecznościowych powinno koncentrować się na kontach użytkowników, publikowaniu treści, komunikacji oraz ochronie prywatności.
